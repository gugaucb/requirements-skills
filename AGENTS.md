# Requirements Skills agent instructions

Before requirements work, read project `docs/agents/` config if present, `docs/VOCABULARY.md`, and actual product `PRODUCT-VISION.md` when available. Use canonical `.agents/skills/<name>/SKILL.md`; skills are small and selective, not a forced pipeline. `setup-requirements-repo` and `create-product-vision` require explicit user initiation; never automatically write/approve a vision. Do not invent a `Skill` tool or claim skill activation that did not occur. Outputs are Markdown; require humans for business decisions and tracker changes.
