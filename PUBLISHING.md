# Publish on GitHub

Extract the ZIP and preserve dot-directories. Verify `python3 scripts/validate_repository.py` and `python3 -m unittest discover -s tests -v`. Create an empty repository and run `git init -b main`, `git add -A`, `git commit -m "Initial Requirements Skills v1.2.0"`, `git remote add origin https://github.com/OWNER/requirements-skills.git`, `git push -u origin main` (replace OWNER). No remote repo has been created by this package. Check license, sources and manual CLI evaluation before tagging a release.
