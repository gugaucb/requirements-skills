# Productivity

General workflow tools, not requirements-specific.

## User-invoked

- **[grill-me](./grill-me/SKILL.md)**: Stateless relentless interview. Writes nothing.
- **[handoff](./handoff/SKILL.md)**: Compact the conversation for another agent or colleague.
- **[wait-what](./wait-what/SKILL.md)**: The last message did not land: re-pitch it.
- **[to-questionnaire](./to-questionnaire/SKILL.md)**: A questionnaire for a stakeholder who holds the answer.

## Model-invoked

- **[grilling](./grilling/SKILL.md)**: The interview primitive (rounds, frontier, change mode with impact round) behind `grill-me`, `grill-with-docs`, `triage`, `wayfinder` and `create-product-vision`.
