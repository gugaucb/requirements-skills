# Triage roles

Canonical role on the left, the actual label string on the right. Defaults: the string equals the role.

| Role | Label | Meaning |
| --- | --- | --- |
| `new` | `new` | Category: a request for something that does not exist yet |
| `change` | `change` | Category: a change to an existing story, capability, goal, decision or term |
| `needs-triage` | `needs-triage` | Evaluation pending |
| `needs-info` | `needs-info` | Waiting on the requester |
| `ready-for-refinement` | `ready-for-refinement` | Specified enough for `/refine-request` or `/split-backlog` |
| `ready-for-po` | `ready-for-po` | Needs a PO decision before anything else |
| `out-of-scope` | `out-of-scope` | Will not be actioned; recorded in `OUT-OF-SCOPE.md` |
