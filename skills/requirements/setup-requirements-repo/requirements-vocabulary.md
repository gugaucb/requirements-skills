# Requirements vocabulary

Shared **process** vocabulary. A product's own business terms live in its `GLOSSARY.md`; do not mix them.

| Term | Definition | Not the same as |
| --- | --- | --- |
| Product Vision | PO-aligned problem, audience, future and scope, revised with evidence | A fixed technical specification |
| Goal (`GOAL-`) | Named objective of the product | A feature |
| Capability (`CAP-`) | Coherent business ability the product must give | A screen or component |
| Spec (`SPEC-`) | Synthesis of one feature or capability: problem, outcome, candidate stories, rules | A story |
| Epic (`EPIC-`) | Optional grouping of stories delivering one outcome | A mandatory Scrum artifact |
| User Story (`US-`) | Thin vertical slice of value, As a / I want / So that | A task list |
| Functional Requirement (`FR-`) | Observable behavior under conditions | An implementation instruction |
| Non-functional Requirement (`NFR-`) | Measurable quality constraint with verification | A vague adjective |
| Acceptance Criterion (`AC-`) | Verifiable business acceptance as a Gherkin scenario | A test case |
| Test Case (`TC-`) | Setup, action and evidence proving an AC | The AC itself |
| Diagram (`DG-`) | Visual clarification of confirmed behavior | A source of new rules |
| Decision (`DEC-`) | Human-made or explicitly pending business choice | An AI inference |
| Change (`CHG-`) | Recorded change to an existing artifact with its impact report | A commit |
| Impact | Items affected by a change: Invalidated, Needs review, Unaffected (checked) | A guess |
| Stale | Status of an item whose upstream changed and has not been re-refined | Rejected |
| Traceability | Verifiable link from intention to acceptance | Keyword overlap |
| Definition of Ready | Optional team agreement on refinement readiness | The Scrum Definition of Done |
| Frontier | Questions or stories whose prerequisites are all settled | The whole backlog |
| Decision ticket | A wayfinder unit holding a question whose answer is a decision | A story |
| HITL / AFK | Human in the loop / agent works alone | |
