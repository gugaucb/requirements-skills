# Requirements

The requirements flow. See [ask-req](./ask-req/SKILL.md) for the map.

## User-invoked

Reachable only when you type them (`disable-model-invocation: true`).

- **[ask-req](./ask-req/SKILL.md)**: Ask which skill or flow fits; reads your artifacts' state first.
- **[setup-requirements-repo](./setup-requirements-repo/SKILL.md)**: Configure artifact root, tracker, language, IDs, triage roles.
- **[grill-with-docs](./grill-with-docs/SKILL.md)**: Grilling that also records glossary, decisions and change impact.
- **[create-product-vision](./create-product-vision/SKILL.md)**: Turn a PO narrative into `PRODUCT-VISION.md`.
- **[to-spec](./to-spec/SKILL.md)**: Turn the conversation into a feature spec. No interview.
- **[split-backlog](./split-backlog/SKILL.md)**: Slice a spec into vertical stories with blocking edges.
- **[refine-request](./refine-request/SKILL.md)**: Refine one story end to end.
- **[triage](./triage/SKILL.md)**: Move incoming requests and change requests through triage roles.
- **[wayfinder](./wayfinder/SKILL.md)**: Chart a huge foggy effort as a map of decision tickets.
- **[retro](./retro/SKILL.md)**: Improve the requirements environment after a session.

## Model-invoked

- **[impact-analysis](./impact-analysis/SKILL.md)**: Impact of a change on downstream, upstream and sideways artifacts.
- **[domain-modeling](./domain-modeling/SKILL.md)**: Build and sharpen business vocabulary and decisions.
- **[review-product-vision](./review-product-vision/SKILL.md)**: Review a vision for consistency and coverage.
- **[write-user-story](./write-user-story/SKILL.md)**: Create or revise a user story file.
- **[specify-requirements](./specify-requirements/SKILL.md)**: Atomic FRs and measurable NFRs.
- **[define-acceptance-criteria](./define-acceptance-criteria/SKILL.md)**: Gherkin acceptance criteria.
- **[design-test-scenarios](./design-test-scenarios/SKILL.md)**: Implementation-independent test scenarios.
- **[diagram-requirements](./diagram-requirements/SKILL.md)**: Mermaid diagrams, only when needed.
- **[audit-traceability](./audit-traceability/SKILL.md)**: Deterministic ID check plus semantic audit.
- **[review-readiness](./review-readiness/SKILL.md)**: Quality gates; never PO signoff.
- **[research](./research/SKILL.md)**: Primary-source research into a cited file.
