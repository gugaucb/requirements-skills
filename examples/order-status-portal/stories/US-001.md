# US-001: Owner sees the current status of an order

**Serves:** GOAL-001, CAP-001 (SPEC-001)
**Status:** Ready for human review

> As an owner, I want to see the current status of my order, so that I do not need to contact support.

## Scope and rules
Statuses: Placed, Shipped, Delivered, Cancelled (DEC-001), On hold (DEC-003). Owners see only their own orders. **Out of scope:** payment details (DEC-002 Pending).

## Functional requirements
| ID | Behavior | Source / status |
| --- | --- | --- |
| FR-001 | A signed-in owner can open the order and see its current status | DEC-001, Confirmed |
| FR-002 | An owner cannot see an order placed by another customer | DEC-001, Confirmed |
| FR-003 | An order blocked by fraud review shows the status "On hold" | DEC-003, Confirmed |

## Non-functional requirements
| ID | Metric / limit | Workload, environment, method | Source / status |
| --- | --- | --- | --- |
| NFR-001 | Status page responds within a target to be agreed | Pending | DEC-004, Pending |

## Acceptance criteria

**AC-001**
```gherkin
Scenario: Owner sees current status
  Given an owner with an order in status "Shipped"
  When the owner opens the order
  Then the page shows "Shipped"
```

**AC-002**
```gherkin
Scenario: Owner cannot see another customer's order
  Given an order that belongs to another customer
  When an owner requests that order
  Then the order is not shown
```

**AC-003**
```gherkin
Scenario: Order on hold
  Given an order blocked by fraud review
  When its owner opens the order
  Then the page shows "On hold"
```
