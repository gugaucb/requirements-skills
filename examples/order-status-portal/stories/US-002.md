# US-002: Owner sees the status history of an order

**Serves:** GOAL-001, CAP-002 (SPEC-001)
**Status:** Stale

> As an owner, I want to see the status history of my order, so that I understand how it progressed.

## Scope and rules
History lists each status the order went through, oldest first (DEC-001 statuses). **Stale:** CHG-001 added "On hold"; the allowed statuses and the sequence rule need review.
